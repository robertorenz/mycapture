Sharing

Where “Share link” uploads your captures. The link is copied so you can paste it into WhatsApp, Teams, Slack or email.

Sharing is off. You can still copy images and video files and paste them straight into chat apps.
AccountNot connected
Captures are saved in a myCapture folder in your Dropbox and shared with a view-only link.
Use your own Dropbox app
This copy of myCapture has no Dropbox app key built in, so set one up once (about 5 minutes):
  1. Go to dropbox.com/developers/apps and choose Create app: Scoped access, App folder.
  2. On the Permissions tab tick files.content.write and sharing.write, then Submit.
  3. On the Settings tab add the redirect URI http://localhost:53682/.
  4. Copy the App key below, save, and click Connect.
AccountNot connected
Captures are saved in a myCapture folder in your OneDrive and shared with a view-only link.
Use your own OneDrive app
This copy of myCapture has no OneDrive app key built in, so set one up once (about 5 minutes):
  1. Open App registrations (Microsoft Entra) and choose New registration.
  2. Supported accounts: any organizational directory and personal Microsoft accounts.
  3. Redirect URI: platform Public client/native (mobile & desktop), value http://localhost.
  4. Copy the Application (client) ID below, save, and click Connect.
AccountNot connected
Captures are saved in a myCapture folder in your Google Drive and shared with a view-only link.
Use your own Google Drive app
This copy of myCapture has no Google Drive app key built in, so set one up once (about 5 minutes):
  1. In the Google Cloud console create a project and enable the Google Drive API.
  2. Set up the OAuth consent screen (External) and add your Google account as a test user.
  3. Under Credentials create an OAuth client ID of type Desktop app.
  4. Copy the Client ID and Client secret below, save, and click Connect.
Run the bundled server anywhere: MYCAPTURE_TOKEN=secret MYCAPTURE_PUBLIC_URL=https://share.example.com mycapture-server. Links get a preview page that shows a thumbnail in chat apps.

A tribute to TechSmith's classic Jing — the launcher, quick captures, quick sharing.
